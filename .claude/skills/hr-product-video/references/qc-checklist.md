# Release checklist

Run `tools/qc.py <project> <shape> --transcribe`, look at `out/qc_sheet.jpg`, then tick every line.

## Content
- [ ] Every fact, number and answer on screen is confirmed by its owner
- [ ] Only live features; "now live" is true on the date the video plays
- [ ] No pay grades, personal data or another region's policy on screen
- [ ] Fictional employee names only; no real chats, photos or contacts

## Sound
- [ ] Transcript matches the script; no stage directions spoken
- [ ] Product name and unusual words checked by ear by the user
- [ ] Pace mostly 130 to 180 words per minute; no sentence flagged without a reason
- [ ] About one second of pause at every scene change
- [ ] Music sits under the voice; loudness about -16 LUFS
- [ ] Music and voice licences cover the use (internal, external, clients)

## Picture
- [ ] No text appears before its words are spoken (check frames around each scene's first word)
- [ ] Captions on one line, no punctuation, no set phrase split across lines
- [ ] Nothing runs into the logo, the brand shapes or the screen edges
- [ ] Every element that appears on a late word stays on screen long enough to read
- [ ] Brand colours, font, logo placement and intro and outro as the guidelines say

## Delivery
- [ ] File name with version number; author and comment metadata empty
- [ ] Approvals listed in the brief are done
- [ ] API keys deleted or rotated if they were shared anywhere
