# References

Material that shows the style you want. Claude looks here before designing a new video.

| Folder | Put here |
|---|---|
| `videos/` | Videos you like, or screenshots of them, with a note on what you like (pace, transitions, captions) |
| `transitions/` | Short clips or GIFs of transitions to copy |
| `music/` | Licensed tracks you may reuse, or notes on the style you want |
| `voice-samples/` | Voices you like, and a note of the ElevenLabs voice ID |

Only keep files you are allowed to store and share. Large videos make the repository slow; prefer short clips.
